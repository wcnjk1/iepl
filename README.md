## 广港 IEPL 到底是什么线

先把概念捋清楚。IEPL（International Private Leased Circuit，国际专线）和 IPLC 一样，走的是运营商之间的专用通道，物理层面就和公网隔离开了，不经过公网拥塞节点，所以延迟稳、丢包率低，晚高峰也不会明显劣化。"广港"指的是广州（或广东）入口到香港出口这个方向。

MKCloud 的广港 IEPL 有几个固定特征，所有套餐通用：

- **入口**：腾讯广州八线动态 BGP，也可选电信、移动、联通或三线接入。八线 BGP 意味着电信、联通、移动、铁通、广电、教育网等多个网络都双向覆盖，用户在哪家运营商就选哪个入口，延迟更可控。
- **出口**：香港 BGP，接的国际路由比较全，访问 Google、Cloudflare、东南亚各地的目标节点都比较顺。
- **IP 配置**：每个套餐都给两个独享 IPv4，一个入口 IP（你连接用）、一个出口 IP（你业务对外展示用）。IP 是你独享的，不是共享池里轮换的那种，所以做电商多账号、直播推流、指纹浏览器这类业务时比较干净。
- **端内延迟**：官方标称 1～2ms。

注意"端内延迟"这个说法，指的是从广州入口到香港出口这一段专线内部的延迟。你实际感受到的总延迟，还要加上你本地宽带到广州入口这一段。所以你家宽带本身质量一般的话，实际 ping 值会比 1～2ms 高，这是正常现象，不是线路问题。

还有一个很多人容易忽略的点：**所有流量计费套餐的月流量都是双向计费的**，上行和下行加在一起算。这意味着如果你每天要往线上传大量商品图、视频素材，实际消耗的流量额度是你直觉估计的两倍。后面选档位的时候要把这个算进去。

## 流量计费 vs 独享带宽：先定计费模式再挑套餐

MKCloud 的广港 IEPL 分两类产品，计费逻辑完全不同：

**流量计费（共享带宽）**：你买一个"月流量包 + 峰值带宽上限"，比如 1TB 流量、200Mbps 峰值。峰值带宽是共享资源，官方不承诺你 24 小时都能跑满 200Mbps，但你短时间的突发上传（比如白天集中传一批商品图）能吃到比较高的速率。流量用完不会停机，会限速，业务不断线。适合用量不固定、有明显波动的业务。

**独享带宽**：你买的是"固定带宽 + 不限流量"，比如 5Mbps 独享。这 5Mbps 是你一个人占用的，什么时候用都是这个速率，不会因为别人在跑流量而变慢。适合需要 7×24 小时持续稳定传输的场景，比如长期在线的监控系统、ERP 数据同步、直播间全天推流。

简单判断方法：**如果你的业务是"每天集中传几小时"，选流量计费；如果是"全天都在持续传输"，选独享带宽**。举个例子，一个人白天管理 10 个店铺，集中上传产品和处理订单，一天实际传 20GB 左右，一个月也就 600GB 以内，买个 1TB 流量计费比独享划算得多。反过来，如果你是做海外仓实时视频监控回传，一天 24 小时都在占带宽，独享 5Mbps 的稳定性就值这个钱。

还有一点值得写出来：**独享款起步价是 500 元/月（5Mbps），流量款起步价是 228 元/月（500GB、150Mbps）**，单看入门门槛差一倍多，但两者的实际体验在高峰期会明显拉开——共享款在多人同时用线的时候可能达不到标称峰值，独享款什么时候都是你自己的速率。预算紧就先用流量款试水，业务跑稳了再考虑升级。

## 不同业务场景怎么选档

**场景一：个人跨境店铺运营（月流量 300GB 以内）**

最典型的是一个人管理一两个跨境店铺，每天操作后台、上传产品图、跑 ERP 同步。这类业务的实际流量消耗：每天 10GB 上行（商品图、库存更新）+ 下行（订单、页面加载）大约 5GB，双向加起来一个月也就 300～500GB。选 **500GB 流量 / ¥228/月**这一档就够，150Mbps 峰值带宽对付单店铺操作完全不是瓶颈。

**场景二：多账号矩阵 + 日常直播（月流量 1TB 左右）**

做 TikTok 或直播带货的人往往不止一个账号，还要长期挂着直播间。直播间推流是持续性的上行流量，加上素材上传，一个月双向 800GB～1.5TB 是常态。**1TB 流量 / ¥358/月**是最多人买的档位，200Mbps 峰值足够支持两三路 1080p 推流同时进行。

如果流量经常不够用，别直接跳 2TB，先算一下实际月用量是多少，再决定是升档还是多个套餐分开跑——多账号业务如果账号之间需要隔离，用两台独立服务器反而更干净，IP 也不会互相影响。

**场景三：团队多人共用（月流量 2TB+）**

几个人一起用一条线办公，或者同时跑多个店铺 + 视频号，流量消耗会快速往上走。**2TB 流量 / ¥568/月**是团队入门的合理档位，300Mbps 峰值带宽足够五六个人同时在线操作、开会、传文件。

这类需求选**独享带宽**系列。5Mbps 独享对长时间持续传输来说不算快，但胜在稳定——这个带宽从早到晚都是你一个人的，不会因为共享线路的高峰期波动而影响业务。适合做海外仓监控、ERP 实时同步、长期在线的代理服务等场景。如果你的业务允许"高峰期偶尔降速"，那还是流量计费更划算。

## 常见问题

**问：广港 IEPL 和普通香港 VPS 有什么区别？**

普通香港 VPS 走的是公网，你的连接要经过公网路由到香港机房，晚高峰容易拥塞、丢包、延迟波动大。IEPL 走的是运营商专用通道，物理上和公网隔离，延迟稳定在低位、几乎不丢包、晚高峰也不受影响。对延迟敏感的业务（直播、实时通信、高频交易）来说，这个差异是决定性的。

**问：1TB 流量到底能用多久？**

取决于你干什么。如果是店铺后台操作 + 商品上传，一个月 1TB 够一个人高强度使用。如果跑视频直播，一路 1080p 推流一小时大约消耗 1～2GB 上行（按码率不同有浮动），加上下行和双向计费，实际月流量会比单纯看推流时长高不少。建议按"预估日流量 × 2（双向）× 30 天"估算，再留 20% 余量选档位。

**问：入口 IP 和出口 IP 有什么区别，为什么给两个？**

入口 IP 是你从本地连接到这台服务器的地址，相当于"门"；出口 IP 是这台服务器访问外部资源时对外显示的地址，相当于"名片"。两个 IP 分开意味着你的业务对外展示的 IP 和你个人连接用的 IP 不是同一个，多账号运营时不容易因为入口 IP 关联而暴露账号关系。这对做多个独立店铺的用户来说是很实际的好处。

**问：能不能当翻墙工具用？**

不能。服务条款明确禁止将服务用于 VPN、代理、绕过防火墙等用途，系统会做合规检测，违规使用会被停机，且不支持退款。这类产品只适合有正规跨境业务需求的用户。

**问：流量用完了会断网吗？**

不会。流量计费套餐的流量用完后会限速，但不会停机，业务不会中断。这也是流量计费模式对波动型业务比较友好的原因之一——你不用精确算好"这个月到底够不够用"，只要不是长期超限，偶尔超一点也就是速度慢一点。

**问：买错了套餐能换吗？**

开通后不支持更换其他地域产品，也就是"广港换沪日"这类操作是做不到的。但同一产品线内的套餐升降级，可以提交工单问一下官方，不同情况处理方式可能不同。下单前确认好地域和方向，比买错了再想办法省心得多。
